# Tesis Miguel 
## Autor Miguel Bueno 

Este repositorio contiene el código desarrollado durante el Trabajo de Fin de Máster "Prototipado y validación en la plataforma RFSoC de un transceptor OFDM de banda ancha para comunicaciones ópticas". 

El material está dividido en 3 carpetas. En la carpeta "Matlab_scripts" están los scripts de Matlab que han servido para simular el comportamiento de los modelos Transmisor y Receptor, y para visualizar los datos capturados durante los experimentos. En "PYNQ_Noteboks" se encuentran la configuración y los pasos necesarios para hacer funcionar cada uno de los Overlays creados para la RFSoC 4x2. En la última carpeta "Vivado_sources" está el código de Verilog y System Verilog utilizados para realizar las operaciones de generación de la PRBS, su detección y el acumulador de errores.
